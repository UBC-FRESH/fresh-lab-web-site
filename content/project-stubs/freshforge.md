# FRESHForge

Status: Open software project (public alpha)

## Public Summary

FRESHForge is an early public-alpha Python package for workflow-as-code in open forest resources and ecosystem services modelling. It composes open FRESH ecosystem tools as typed, version-controlled, executable graphs.
