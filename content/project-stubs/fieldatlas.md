# FieldAtlas

Status: Early-stage open software project

## Public Summary

FieldAtlas is an early-stage iPhone field map app built around offline, georeferenced map packages. It is intended to help field users load trusted public map packages, inspect their location against those maps while offline, and retain reproducible metadata about map provenance.
