# BC Native Plant & Pollinator Database

Status: Early-stage open data and software project

## Public Summary

The BC Native Plant & Pollinator Database (BC-NPPD) is an evidence-based native plant and pollinator decision-support database for coastal British Columbia. Initial scope focuses on low-growing native species suitable for urban landscapes in Metro Vancouver, the Fraser Valley, and related coastal BC contexts.
