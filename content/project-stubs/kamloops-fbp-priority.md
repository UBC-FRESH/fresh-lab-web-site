# Kamloops Fire Centre fuel-treatment priority mapping

Status: Ongoing MGEM project

## Public Summary

This MGEM project is developing a reproducible Fire Behaviour Prediction screening workflow for fuel-treatment priority mapping across the Kamloops Fire Centre. The feasibility prototype covers a 71,579 square-kilometre study area and a three-zone method test in the ICH, IDF, and PP biogeoclimatic zones.
