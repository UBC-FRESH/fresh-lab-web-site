# FRESH-CBM

Status: Open software project

## Public Summary

FRESH-CBM stores deterministic per-hectare carbon accounts produced by libcbm for a declared package and treatment family, letting WS4 and FEMIC analyses look up a stand state instead of rebuilding a CBM model for every analysis.
