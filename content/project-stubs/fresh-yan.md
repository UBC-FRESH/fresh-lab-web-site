# FRESH-Yan HWP uncertainty analysis

Status: Ongoing manuscript and software project

## Public Summary

This project provides open, reproducible code, data, and results for a Canadian Journal of Forest Research manuscript on whether the climate-optimal harvest level is identifiable from current harvested wood product evidence.
