# FRESH-FVSbc

Status: Open software project

## Public Summary

FRESH-FVSbc is a Python wrapper for the BC variant of the Forest Vegetation Simulator (FVS). It builds the FVSbc variant from a pinned fork of PyFVS and exposes BC keywords, species and BEC handling, and tidy simulation input and output.
