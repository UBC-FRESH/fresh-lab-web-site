# WS4

Status: Open software project

## Public Summary

WS4 is the Wood Supply Simulation System (Spatially explicit), an open-source, CLI-first forest estate model for multi-core Linux environments. It treats fragments as decision units and blocks as runtime aggregates, enforcing adjacency, patch structure, and road access during simulation and optimization.
