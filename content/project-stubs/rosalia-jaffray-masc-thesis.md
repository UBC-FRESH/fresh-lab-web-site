# Rosalia Jaffray MASc Thesis

Status: Past project

## Public Summary

A completed MASc thesis developing and evaluating FHOPS, an open-source machine-scheduling tool for forest operational planning.

Rosalia Jaffray's MASc thesis developed and evaluated FHOPS, the Forest Harvesting Operations Planning System, as an open-source tool for machine scheduling in forest operational planning.
