# FRESH-Fuchs risk-aware forest planning

Status: Ongoing research and software project

## Public Summary

FRESH-Fuchs is a stochastic, risk-aware forest landscape planning model on the TSA29 mini instance. It couples a policy-level Monte Carlo outer problem with an enterprise-level harvest-scheduling linear program.
