# FRESH Solutions

Status: Open software project

## Public Summary

FRESH Solutions is a general, reproducible hybrid metaheuristic solver for hard combinatorial optimization. It extracts the search architecture developed in WS4, including exact incremental accounting, CPU local moves, batched GPU population search, and exact replay of reported incumbents.
