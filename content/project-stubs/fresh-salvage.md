# FRESH-Salvage TSA29 salvage-subsidy model

Status: Ongoing research and software project

## Public Summary

FRESH-Salvage is an open-source Python package implementing a linear principal-agent salvage-subsidy model for the Williams Lake Timber Supply Area in British Columbia.
